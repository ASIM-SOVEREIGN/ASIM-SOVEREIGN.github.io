# Landing Page #3 — Dark/Bold Style

A dark, aggressive landing page with neon cyan accents. Built for bold brands and high-energy products.

---

## What You Get

- `index.html` — Main HTML structure with clear placeholders
- `css/style.css` — Complete styling with dark/neon theme
- `js/main.js` — FAQ accordion, smooth scroll, mobile hamburger menu
- `json/config.json` — Data file for dynamic content
- `assets/` — Placeholder images and icons

---

## How to Use

1. **Replace Placeholders** — All text in `[BRACKETS]` is a placeholder. Replace it with your own content.
2. **Customize Colors** — Open `css/style.css` and edit the `:root` variables at the top.
3. **Add Your Logo** — Replace `assets/images/logo-placeholder.svg` with your own logo.
4. **Update Images** — Replace all placeholder images in `assets/images/` with your own.
5. **Test Locally** — Open `index.html` in your browser to preview.

---

## Customization Guide

### Colors
Open `css/style.css` and edit these values:

```css
:root {
    --primary-color: #00F5FF;    /* Your neon accent */
    --secondary-color: #0A0A0A;  /* Dark background */
    --text-color: #FFFFFF;       /* White text */
}
